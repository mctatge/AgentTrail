# Visual assets

## Documentation screenshots

These are genuine native-app screenshots of AgentTrail 0.2.1 showing only the synthetic demonstration generated by `Sources/TrailCore/Demo.swift`.

- `timeline.jpg`: the action timeline and Command-D evidence inspector.
- `cursor-trail.jpg`: the coordinate map, drag/movement paths, button markers, and sample playback controls.

The example workbook name, selection, application context, and input events are fabricated. Displayed dates identify the generated example, not a real user activity log. No third-party application window or document is pictured. The example uses a spreadsheet to illustrate the interface; AgentTrail records inputs across applications.

## Capture procedure

Use a separate temporary `--root` library populated with the CLI's `demo` command. Launch a local build against that same library, select the synthetic session, and open its evidence inspector and cursor trail. Never start recording or point the documentation preview at a personal recording library. Capture only the app window or trail sheet, excluding the desktop and other windows.

These images were captured from an isolated documentation-preview app copy using a separate bundle identifier. The preview did not request capture permissions or change the installed recorder's library. The image bytes are the window screenshots as returned by the capture tool, without fabricated UI or compositing. No generated database or raw event export is included in the repository.

## Review before publication

Visually inspect every image, check its metadata, and verify that no real documents, identities, credentials, personal paths, or unrelated windows appear. Generate new examples rather than blurring private recordings. Check that captions accurately distinguish synthetic examples from real capture.

The publication guard allows only the two named documentation screenshots and the two app-icon files listed below, with their reviewed SHA-256 hashes in `scripts/check-publication.py`. Any replacement requires renewed review and an explicit hash update. `.gitignore` has matching exact-path exceptions; it does not allow arbitrary screenshots. Run the publication tests and staged-index check before pushing.

Hashes detect changed bytes; they do not inspect pixels, anonymize data, establish data rights, or replace human review. Do not approve an image merely to make the check pass.

## Application icon

- `Resources/AppIcon.png`: original 1024-pixel app-icon artwork, created for AgentTrail with image generation and visually reviewed. It contains no captured user content.
- `Resources/AppIcon.icns`: the macOS icon compiled from that artwork, with standard icon sizes generated using Apple's image tools.

The build script copies the ICNS file into the app bundle. These exact paths and reviewed hashes are approved; unrelated resource images and icons remain blocked. Review any replacement artwork and update its hashes before publication. The PNG source has one exact-path `.gitignore` exception.
